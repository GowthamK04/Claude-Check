# Claude-Check — UPSC notes archive

Layout: `<Subject>/<Type>/<Sequence>_<File>`

- **Subject** — Modern History, Anthropology, Polity, …
- **Type** — `Notes` (topic packets, PDF), `Mind Maps` (A3 maps, PDF), `Revision Sheets` (markdown)
- **Sequence** — the topic's `Sequence` number in the Notion Subject Coverage database, zero-padded to two digits so files sort in study order

Example: `Modern History/Notes/22_MH_GS1_27-28_British_Policies_and_Economic_Impact.pdf`
